# 真机截图（可选）

放一张 `dashboard.png`（中控 1920×1080）进来，落地页的「功能」段尾就会自动显示它；
文件不存在时那一块整体隐藏，不会出现破图。

想多放几张也没问题，但页面目前只用第一张 —— 需要多个角度时再改 `assets/app.js` 的
`CONFIG.shot`。

截图不要超过 1 MB：Pages 对单文件 100 MB、整站 1 GB，但车机网络看页面时大图很慢。
用 `tools/dev.sh shot <名字>` 出来的原图通常 1 MB 上下，可以先压一下再提交。

注意：截图会进 git 历史，删掉也还在。真车界面里如果有车牌、位置、行程这类隐私，
先裁掉或打码。
