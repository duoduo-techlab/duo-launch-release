Duo Launch 是长城哈弗 B16（骁龙 8155 / Android 9）上的第三方桌面。 不刷机、不要 root、不碰平台签名：界面全部自绘，厂商能力当可降级的依赖 —— 绑得上就消费，绑不上就退回静态展示或原厂页面，桌面本身始终可用。

不是悬浮窗，也不是投屏

原厂 com.gwm.app.launcher 是系统签名 + persistent 应用，每次进程启动都会把默认 HOME 改回自己； 左侧导航栏和顶部状态栏永远属于 SystemUI。平台签名拿不到，所以 Duo 换了一条路。

替换默认 HOME

注册 HOME + LAUNCHER，可设成默认桌面；再叠一层开机自启与 Home 键抢回，不依赖系统「记住上次选择」。

地图铺满，导航照抄原厂

右侧 70% 是原厂高德地图的实时画面，HUD 主卡尺寸与配色取自原厂车机皮肤：转向箭头、车道图、电子眼气泡都是真的。

多媒体一条线

GUX 媒体总线优先、网易云兜底：封面模糊铺底、旋转 CD、歌词、进度与播放控制都在左列一张卡里。

空调与座椅直控

主副驾温度、风量、座椅加热与通风走原厂 Binder；车机拒绝 setData 时自动降级跳原厂空调页，不假装成功。

方控与倒挡

方控键可以绑到任意目标页；挂 R 挡（去抖 500ms、一次会话只触发一次）自动拉起 360 影像，退出即回桌面。

崩了也能开车

崩溃记录 + 连续崩溃进安全模式：先把 GUX、方控、地图实时渲染这些非核心能力摘掉，必要时回原厂桌面。

装上去，大概三分钟

车机是 user 构建：不能 adb root、没有 su，但能侧载安装。三种方式任选其一。

1

拿到 APK

页面上的「下载」永远指向最新正式包；历史版本在 版本记录 里。包名 com.duo.launcher，签名是固定的调试签名，所以后续版本可以覆盖安装。

2

装进车机

adb devices
adb install -r duo-launcher.apk
adb shell am start -n com.duo.launcher/.MainActivity

提示 INSTALL_FAILED_UPDATE_INCOMPATIBLE = 之前装过别的签名：先 adb uninstall com.duo.launcher 再装（会清掉主题与崩溃记录）。

  1. 把 duo-launcher.apk 拷到 FAT32/exFAT U 盘根目录或 Download/。
  2. U 盘插车机 → 用车机自带的文件管理器打开 APK → 允许「未知来源应用」。
  3. 部分固件会拦第三方安装，需要在「设置 → 应用 → 特殊权限 → 安装未知应用」里给文件管理器授权。
3

设为默认桌面

adb shell cmd package set-home-activity com.duo.launcher/.MainActivity

也可以走车机 UI：设置 → 应用 → 默认应用 → 主屏幕 → Duo 桌面。首次启动会弹一次桌面选择器，选 Duo 并勾「始终」。

↩

想退回原厂桌面

Duo 不修改任何系统分区，随时可以退回：

adb shell cmd package set-home-activity com.gwm.app.launcher/.LauncherActivity
# 或者直接卸载
adb uninstall com.duo.launcher

原厂 launcher 是 persistent 应用，卸载 Duo 后下次开机自然回到原厂桌面。先拍照记下原厂桌面样子，方便核对。

常见问题

会顶掉原厂桌面吗？会改系统吗？

不会改系统分区，也不写入任何系统应用。Duo 只是把自己注册成可选 HOME；你选它为默认桌面之后，按 Home 才会进 Duo。 「设为默认」是系统设置，随时可以改回去，卸载 Duo 后自动恢复。

为什么是调试签名？安全吗？

车机装不了平台签名之外的系统应用，也不需要 —— 普通第三方应用就够用。签名固定保存在 CI 的 secret 里，所以版本之间可以互相覆盖安装。 代价是别人拿到同一个密钥就能覆盖你的 Duo，因此更新请只从本页或 GitHub Release 下载，并核对页面上的 SHA256。

需要联网吗？会收集数据吗？

日常使用完全不联网：车辆数据、媒体、地图全部来自车机本地的厂商服务和已装应用。 唯一的可选网络请求是「设置 → 关于 → 检查更新」，只 GET 一张版本清单 JSON，不上报安装 ID、不做统计。

会自动更新吗？

不会。车机是 user 构建，没有应用商店也无法静默安装，所以检查更新只做「告诉你有没有新版」，装不装、怎么装仍由你决定。 本页的下载按钮永远指向最新正式包，用 ADB 覆盖安装即可。

支持别的车型吗？

只针对哈弗 B16（GWM / 骁龙 8155 / Android 9 / 1920×1080）调过。其他 GWM 车型理论上能看到界面，但车辆字段、方控键位、厂商组件名都要先用应用内的「兼容性自检」确认，绑不上的能力会降级或隐藏。

装完黑屏 / 一直闪回怎么办？

连续崩溃会触发安全模式并尝试回原厂桌面。如果还卡着，插上 ADB：

adb shell cmd package set-home-activity com.gwm.app.launcher/.LauncherActivity
adb uninstall com.duo.launcher

改完不用刷机，也不会留下残留。

这个项目的源码在哪？

主线开发仓库是私有的，没有公开计划。本仓库只做两件事：放发布产物、放这个介绍页。
